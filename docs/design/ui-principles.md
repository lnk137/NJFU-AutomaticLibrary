# 界面优化原则

来源：主线 `docs/superpowers/specs/2026-10-24-concise-interface-design.md`，2026-10-24 同步。

默认只呈现状态、关键数字和下一步操作。规则、版本、统计口径及系统细节放进可展开的说明；普通提示用轻量中性色，错误、未生效和待核对情况直接显示。

- 管理端先显示异常和待处理事项，正常账号与重复说明按需展开。
- 每个区域只解释一次。同一规则不在标题、提示、列表和保存结果中反复出现。使用短句、熟悉的词。
- 缩短文字不能掩盖真实状态：同步不等于预约成功，空同步快照不代表待同步，学校回执才能证明预约成功。
- 会改变用户决定的信息留在操作附近：周五20:00、至少2小时、未保存内容、异常结果，以及“确认后定时计划生效、当天预约立即提交”。
- 日期调整显示日期和动作；收藏显示自己的座位、分组和标签；撞座显示日期、座位、重叠时间和相关账号；个人表单每份一人，审阅保留申请人的预约类型、时段、座位和验证结果。
- 保留绿色品牌、清晰的选中/展开状态、键盘焦点与足够的触控区域。分别检查电脑、iPad和手机，长名称、标签和账号不得造成横向溢出。
- 通过信息层级和留白减轻密度，不靠隐藏错误、删操作或改变预约行为来实现简洁。

界面改动验证需要包含：默认与展开状态、异常可见性、重要操作入口、多尺寸实际浏览器回读，以及既有预约和计划回归。构建成功不等于界面验收完成。
