# Email notifications

邮件为可选服务，使用 Python 标准库 SMTP，接受 TLS 或 STARTTLS 并验证证书。不安装新依赖。配置缺失或无效时邮件关闭，预约调度继续运行；root 的“管理员”页可检查邮件服务状态。

## Local sender configuration

在实际执行后台的数据目录创建 `mail.json`，仅当前用户可读写（0600），目录与文件不可为符号链接。文件包含发件授权信息，不加入 Git，不粘贴到聊天或日志。用邮箱服务提供的参数和客户端授权码替换以下占位值：

```json
{
  "enabled": true,
  "host": "smtp.example.com",
  "port": 465,
  "security": "tls",
  "username": "sender@example.com",
  "password": "ENTER_LOCALLY",
  "from_address": "sender@example.com",
  "from_name": "图书馆预约"
}
```

STARTTLS 使用服务商指定端口和 `"security":"starttls"`；不支持明文 SMTP。候选安装时再配置并启动，本次开发不创建正式配置、不启用现用后台、不发送真实邮件。配置在后台启动时读取，正式启用需安排单独的服务加载验证。

## Recipient workflow

学生自行验证收件邮箱，分别开启结果通知和使用前提醒，默认提前30分钟。收件地址在专用集合加密保存，验证码限时、限次且不明文入库；API只返回掩码邮箱。设置不改变预约计划版本。root 可以为选中账号进入设置，验证码仍由收件邮箱本人接收。

发信使用独立、有界持久队列，避开放号准备/执行窗口，不占预约账号锁。重复扫描与重启不重复发信；发送结果不明时保留待核实，不自动重发。首次开启不回灌历史。提醒依据已保存学校有效回执（最长36小时缓存，正文注明核对时间），已取消、身份不明、证据矛盾或过期时段不提醒。垃圾箱分类、送达时间和手机弹窗需真实邮箱验收，手机需开启邮箱通知。

有公网入口时链接指向 `public_origin`；仅本机模式注明链接只能在执行电脑打开。扫描或预览链接只执行 GET，取消仍需登录、核对并确认。执行电脑离线或睡眠时不能按时发信，过期提醒不补发。

使用前提醒邮件仅保留一个 HTML 按钮“取消预约”，纯文本邮件保留相同功能的备用链接。点击后自动核对并取消邮件中的这条预约，不需要登录或再次确认；打开的轻量页面只显示处理结果。仅取消这一段，其他时段与定时计划保留。旧邮件的普通详情链接继续沿用原登录、核对和确认流程。

普通邮件预览、GET/HEAD 扫描不执行取消。短期导航凭证用于识别浏览器点击，执行请求还须提供与账号、精确预约、邮箱绑定和凭据版本一致的签名能力。链接到期不晚于预约开始，更换邮箱/凭据或撤销准入后拒绝；这是单条预约的短期取消授权，请勿转发。导航标记不能保证识别主动伪装真实用户点击的扫描程序。

服务端在学校查询前持久声明一次处理资格，重复点击只读取结果。中断、发送不明或网络超时只查询已有取消结果，不自动重交。链接中的授权放在 URL fragment，页面读取后立即移除，不写入服务器查询串日志；客户端只保存摘要形式的已尝试标记。
